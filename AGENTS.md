# Evelin Boutique

## Regras gerais
- Não inventar preços, tamanhos, nomes ou cores.
- Usar somente informações confirmadas no catálogo fornecido.
- Não alterar o número do WhatsApp sem autorização.
- Não excluir arquivos sem confirmação.
- Preservar o funcionamento atual do site.
- Preservar a responsividade.

## Produtos
Cada produto deve ter:
- nome
- categoria
- preco
- tamanhos
- cores
- imagem

Se alguma informação não estiver disponível:
- usar null quando fizer sentido
- não inventar dados

## Imagens
- Salvar imagens em `assets/imagens/produtos/`
- Usar nomes em minúsculas
- Não usar espaços
- Usar hífens

Exemplo:
`blusa-jessica.png`

## Código
- Manter o código organizado.
- Não reescrever partes que já funcionam sem necessidade.
- Explicar alterações importantes.
- Antes de mudanças grandes, apresentar um plano.

## Segurança do projeto
- Não fazer commit ou push sem autorização.
- Não alterar arquivos fora deste projeto sem autorização.
- Antes de alterações grandes, explicar o plano.
- Não sobrescrever imagens existentes sem necessidade.
- Se faltar alguma informação de um produto, informar o que está faltando em vez de inventar.

## Catálogo
- Usar somente produtos e imagens autorizados pelo fornecedor.
- Manter o nome original do produto quando ele estiver disponível.
- Não alterar preços encontrados no catálogo.
- Separar corretamente os produtos entre Vestidos, Blusas e Saias.
- Antes de cadastrar muitos produtos, testar o processo com 1 produto.
